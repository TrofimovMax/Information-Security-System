Разработка модуля заявки на обучение в рамках компании предоставляющая информационное обеспечение для групп компаний. Поставляет ПО, занимается администрированием и поддержкой этого ПО.

#### Swagger
swagger-cli validate openapi\openapi.yaml
swagger-cli bundle openapi\openapi.yaml --outfile openapi\dist\openapi.bundle.yaml --type yaml
swagger-cli bundle -r openapi\openapi.yaml --outfile openapi\dist\openapi.deref.yaml --type yaml
