# User Story и критерии приёмки для модуля «Заявки на обучение»

## US-01. Создание заявки на обучение

Как Пользователь модуля, я хочу создать заявку на обучение через веб-форму, чтобы ускорить процесс подачи и обработки, и сохранить данные в истории.

**Критерии приёмки:**

- Пользователь может открыть форму создания заявки в модуле «Заявки на обучение»;
    
- Форма содержит все необходимые поля;
    
- Пользователь может добавить список учеников вручную через веб-форму;
    
- Реализована функция автоматического заполнения данных ученика по его ФИО;
    
- Пользователь может скачать шаблон Excel-файла для заполнения списка учеников;
    
- Пользователь может загрузить список учеников из Excel-файла установленного формата;
    
- После загрузки Excel-файла Система отображает список учеников в форме заявки;
    
- Пользователь может вручную отредактировать список учеников после загрузки Excel-файла;
    
- Система выделяет незаполненные обязательные поля;
     
- Система выделяет дубли в списке учеников;
    
- При ошибках валидации Система отображает сообщение с причиной ошибки;
    
- При успешной отправке Система сохраняет заявку и присваивает ей советующий статус;
    
- Пользователь может сохранить незавершённую заявку как черновик;
    
- Пользователь может загрузить ранее сохранённый черновик и продолжить заполнение заявки;
- Пользователь может отсортировать список учеников;
    
- Пользователь может отфильтровать список учеников;
    
- Пользователь может производить поиск по списку учеников;
    
- Пользователь может выбрать количество учеников отображаемых на странице;
    
- Реализована пагинация списка учеников.

---

## US-02. Просмотр списка заявок

Как Пользователь модуля, я хочу просматривать список заявок с возможностью поиска, фильтрации и сортировки, чтобы быстро находить нужные заявки и отслеживать их состояние.

**Критерии приёмки:**

- Заявитель может просматривать список своих заявок;
    
- Согласующий может просматривать список всех заявок, доступных ему в соответствии с ролевой моделью;
    
- Система отображает только те действия с заявками, которые доступны пользователю согласно его роли;
    
- В списке заявок для Пользователя отображаются заявки в табличной форме, таблица содержит все необходимые столбцы;
    
- Пользователь может удалить черновик из списка заявок.
    
- Пользователь может выполнять поиск по списку заявок;
    
- Пользователь может фильтровать заявки;
    
- Пользователь может сортировать заявки;
    
- Пользователь может выбрать количество заявок отображаемых на странице;
    
- Реализована пагинация списка заявок;
    
- Реализована функция для выбора нескольких заявок;
    
- Пользователь может скачать отфильтрованный список заявок, доступных ему по роли;
    
- Пользователь может скачать выбранные им заявки для просмотра, доступных ему по роли;
    
- Пользователь может открыть карточку со всеми данными выбранной заявки из списка.

---

## US-03. Рассмотрение заявки

Как Согласующий, я хочу проверить заявку и принять по ней решение, чтобы корректные заявки были переданы в СДО.

**Критерии приёмки:**
- Карточка заявки содержит все необходимые поля;
    
- Согласующий может скачать заявку;
    
- Согласующий не может рассматривать заявку, которую он сам создал;
    
- Согласующий может согласовать корректную заявку;
    
- Согласующий может отклонить заявку, если она не может быть принята;

- Согласующий может отправить заявку на доработку, если в ней есть исправимые ошибки;
    
- При отклонении Согласующий должен указать комментарий с причиной отклонения;
    
- При отправке на доработку Согласующий должен указать комментарий с деталями которые нужно скорректировать;
    
- После принятия решения заявка отображается списке заявок с соответствующим статусом;
    
- Согласующий может отсортировать список учеников;
    
- Согласующий может отфильтровать список учеников;
    
- Согласующий может производить поиск по списку учеников;
    
- Согласующий может выбрать количество учеников отображаемых на странице;
    
- Реализована пагинация списка учеников.
